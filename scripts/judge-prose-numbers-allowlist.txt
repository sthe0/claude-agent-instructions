# judge-prose-numbers-allowlist.txt — one entry per judge-latency number written
# in the prose of a `judge-prose-domain.txt` file, each carrying the reason a
# human re-read it against the current calibration.
#
# Grammar:  <repo-relative path>:<line>:<sha8>  # <reason>
#
# The sha8 is `sha256(line.strip())[:8]` — a CONTENT anchor, so the entry
# survives an unrelated insertion above it and dies the moment the governed
# sentence itself is reworded. The reason is MANDATORY: a bare path only records
# that somebody once saw a number, which is the state this check exists to end.
# Say where the number comes from — a rule in lib/judge_latency.py, an approved
# budget, or a superseded measurement quoted as the defect it documents.
#
# Four-way resolution (verify-judge-prose-numbers.py::resolve_entries):
#   * anchor matches at the pinned line         -> covered;
#   * anchor matches exactly one other line     -> relocated, still covered, and
#                                                  the move is reported;
#   * anchor matches nowhere                    -> STALE: the sentence was
#                                                  rewritten, so the reason was
#                                                  written about text that no
#                                                  longer exists. Re-read it;
#   * anchor matches several lines              -> ambiguous, hard failure.
# Two entries resolving onto ONE occurrence is also a failure: one of them
# silently double-covers while the occurrence it named resurfaces as unallowed.
#
# `verify-judge-prose-numbers.py --repin` rewrites line numbers and anchors for
# every cleanly-resolved entry, preserving each reason byte for byte, and refuses
# to touch a stale or ambiguous row — a repin must never invent a reason.
#
# Accepted limits: the prefilter is lexical, so a number spelled as neither a
# duration nor a named statistic ("well under half a minute") is not governed at
# all; and a reason can be written carelessly, which no check can detect. What
# the mechanism guarantees is narrower and still worth having: no governed
# sentence changes without a human re-reading the reason attached to it.
