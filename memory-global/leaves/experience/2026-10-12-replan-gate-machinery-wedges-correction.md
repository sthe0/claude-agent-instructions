# The replan gates that must admit a correction stall it, or strand the session, instead

## Difficulty
Once a control defect is diagnosed the repair is routed through replan. The premise gate's enumeration goes stale and blocks a refinement until the canonical plan content is synced; a replan that only narrows a done criterion is classed substantive and leaves the session at PARTITIONED with all stages passed; the coverage gate's encoding for a control-only change was not obvious. Each wedge turns a one-line repair into a recovery exercise with no reachable route.

**Functional ground:** The correction path for a defective control passes through gates (premise enumeration, replan classification, coverage) whose own state or classification can stall it, so the repair of an authoring slip needs a second repair of the machinery.
