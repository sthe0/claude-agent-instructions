# Coordination-practice sub-index (redundant with CLAUDE.md)

Every entry below is also named inline in `CLAUDE.md` (the always-loaded root instructions), so the root index does not need to repeat it to keep the norm visible in every session — CLAUDE.md already carries that visibility. This sub-index exists to shrink `memory-global/MEMORY.md` under its byte ceiling, not to re-organize by topic; membership is mechanical: a leaf sits here **iff** its filename stem occurs somewhere in `CLAUDE.md`. **Drift hazard:** if CLAUDE.md later stops naming one of these leaves, that leaf's only always-loaded notice disappears — check on CLAUDE.md edits, and move the entry back to the root index if its stem is removed.
