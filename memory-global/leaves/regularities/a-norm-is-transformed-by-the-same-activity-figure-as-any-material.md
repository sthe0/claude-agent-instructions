# Every reflexive operation of the agent system

## Regularity

Every reflexive operation of the agent system — self-improvement, overcoming a difficulty, proactive self-diagnosis — decomposes without remainder into the elements of the base activity figure ([[plan-activity-ontology]]): the norm being changed occupies the place of the material, the re-norming edit is the transformation, the corrected norm is the product, and the difficulty that triggered it is the order. No element of these operations has been found that needs a place the base figure does not already have.

## Generality

Level 3 — ranges over the agent system's own reflexive operations, whose material is its norm-set. It is not claimed for activities outside that system, whose decomposition the observations did not test.

## Refutation

A reflexive operation with an element that occupies no place of the base figure — a part that is neither material, means, method, actor, condition, knowledge, criterion nor product — would show the decomposition is not without remainder.
