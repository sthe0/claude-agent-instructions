# a-plan-checked-only-against-itself-passes-over-premises-it-leaves-unrecorded-and-parts-of-the-order-it-leaves-out

## Regularity

An ungrounded planning leap stated in confident prose names no record bound to a plan element, so a reviewer has nothing to address; and a plan authored over only part of a multi-part order passes every gate that reads the plan alone, because each such gate compares the plan to itself or to the critique and the narrowing is compared to the order nowhere. A false premise or a dropped part of the order is then paid for in execution before any resolution-time check runs.

## Generality

Level 1 — ranges over substantive plans approved through gates that read the plan alone, with premises stated in prose and orders of several parts. It is deliberately not claimed for plans whose premises and order elements are recorded as named records and compared with the order.

## Induced from

- [[question-provenance-gate]] — contributes the observed case behind the statement: a plan authored over half of a two-part order passed every downstream gate, and ungrounded premises dissolved in confident plan prose.

## Refutation

A plan authored over only half of its order that a plan-only gate (one not given the order's elements) nonetheless rejected for that omission, or an ungrounded premise in plan prose that a reviewer reliably caught without any named record, would show plan-only checking reaches these gaps.
