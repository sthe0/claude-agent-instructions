# a-memory-that-records-every-task-charges-later-tasks-for-entries-they-never-use

## Regularity

A memory that gains an entry for every resolved task grows whether or not a later task would have to rediscover that entry's content; the always-loaded memory surface then costs every later task reading effort for entries it never uses, while a difficulty left unrecorded costs only the later tasks that meet it again.

## Generality

Level 1 — ranges over agent memories that are partly loaded into every session and gain entries at task resolution. It is deliberately not claimed for memories read only on demand through retrieval, where an unused entry costs nothing at load time.

## Induced from

- [[recording-experience]] — contributes the observed practice behind the statement: recording every resolved task bloats the always-loaded memory surface, which is why a quality bar decides what is recorded.

## Refutation

A memory that recorded every resolved task and whose growth demonstrably added no cost to later tasks (no longer retrieval, no larger loaded surface), or a long run of unrecorded difficulties whose recurrence cost more than the recorded noise, would show the asymmetry does not hold.
