# a-ground-that-is-not-recorded-experience-names-no-refuting-observation

## Regularity

An action in a plan is predictable only when it is grounded in a regularity; an experience is a trivial regularity. A rule or a prohibition has no bearing on predictability: it can serve only as a given constraint, a condition within which the plan is built.

## Generality

Level 1 — ranges over plans in this agent system whose stages name a ground for a prescription they adopt. It is deliberately not claimed for the correctness of a ground's content, only for which kind of ground can make an action predictable and which can only constrain the plan.

Generalized from an order on 2026-10-29.

## Induced from

No leaf: this regularity is generalized from the order quoted in "Derived from order" above, not from recorded experience or a rule leaf.

## Refutation

Refuted by a plan action grounded in a rule or a prohibition alone whose outcome could nevertheless be predicted from that ground before it ran; or by an action grounded in a regularity whose outcome, within the regularity's stated scope, could not be predicted from it. Also forced broader if a ground of some further kind turns out to make actions predictable as a regularity does.
