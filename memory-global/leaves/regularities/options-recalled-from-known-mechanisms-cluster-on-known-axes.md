# An option set produced by recalling mechanisms one already knows varies along the axes those mechanisms already occupy and misses options on axes no recalled mechanism sits on

## Regularity

An option set produced by recalling known mechanisms clusters on the axes those mechanisms already occupy: the options differ in implementation detail along one or two familiar dimensions (which store, which hook, which file) and leave out whole regions of the design space — passive mechanism against active agent, per-item against batch, mechanical precedence against a synthesized invariant — on which no recalled mechanism happens to sit. Options derived from the function the solution must serve vary along those missing axes as well, because the function does not inherit the recalled mechanisms' shared assumptions.

## Generality

Level 3 — ranges over any design or architecture question answered by enumerating alternatives. It is not claimed for a question whose option space is closed by an external specification (a protocol that admits exactly three modes).

## Refutation

A run of design questions on which a recalled-mechanism option set and a function-derived option set covered the same axes, or on which the recalled set contained the eventually chosen option every time, would show the clustering does not occur for that kind of question.
